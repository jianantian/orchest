# Hotfix 2026-08-05 PRD:手机 header 修复 + 创作室重设计

## 背景

2026_08_02c 一致性收敛后,用户实际使用反馈两点:

1. **手机 header 乱**:`创作/发现/我的` 三个两字导航标签在窄屏竖向折行,与主题切换、语言、头像挤成两排(有用户截图实证);
2. **创作室"太堆功能"**:左栏平铺 7 个控件区(模式分段控件、歌词、风格输入、已选 chips、14 个常驻建议、更多选项手风琴、标题、生成按钮),右栏 AI 面板又能做同样的事——双重入口互相抢视线,一屏内没有主次。

设计决策(已与产品确认):

- **手机 header**:导航标签 `white-space: nowrap` + 移动端收紧 padding/字号;不够再收主题/语言进头像菜单(第一步只做 nowrap+紧凑);
- **创作室重设计**——"稿件为主,属性收成一行,灵感收进对话":
  - 左栏 = 稿件文档:标题(AI 起名、点击即改)→ 歌词编辑器(唯一主角)→ 属性条一行(风格 chips + `[女声|男声|器乐]` 三态 pill)→ 底部生成按钮;
  - 14 个常驻风格建议 → **空态轻建议**(风格为空时显示 3-4 个,填入即消失);更多灵感走 AI 对话;
  - 右栏 AI 协作**固定窄栏**(~380px),改动实时映射左栏并高亮,撤销保留;
  - 拆除:大分段控件、更多选项手风琴、常驻建议云、标题独立 section;左栏从 7 个控件区减到 4 个视觉块;
  - 交互原则:一屏只做三件事——写/改歌词、瞟属性、点生成。

## 目标

1. 手机 header 单行不折行、不拥挤;
2. 创作室桌面双栏(稿件 + 固定窄栏 AI),控件收敛为标题/歌词/属性条/生成按钮四块;编辑模式(版本切换、保存/再生成)在新布局中原位保留;
3. 移动端维持"草稿 / AI 协作"双 tab,结构同构。
