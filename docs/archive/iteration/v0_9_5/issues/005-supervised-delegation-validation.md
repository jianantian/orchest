# 005 · Supervised Delegation validation notes

## Background

Supervised Delegation remains a core validation case: a long-running delegated agent is monitored through event streams and can be steered mid-run.

## Goal

Keep Supervised Delegation visible as a validation scenario for v0.10 and later long-running agent-tool products.

## Acceptance Criteria

- [x] Roadmap or iteration docs mention that v0.10 should validate at least the lightweight form of reviewer sub-agent or handoff.
- [x] Long-running Claude-Code-as-tool style delegation remains documented as a future validation scenario, not a v0.10 requirement.
- [x] Docs distinguish Agent-as-Tool, Handoff and supervised long-running delegation.
- [x] No runtime implementation is required in this issue.

## Notes

This issue is documentation-only unless v0.10 planning uncovers a concrete missing runtime primitive.
