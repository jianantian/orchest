# Multivac Design——视觉基调与品牌

> 2026-06-12 | 上游：[ADR-001](./adr-001-product-positioning.md)（介质论、人读审指 agent 写、厚度 = 时间 × 沉淀）
> 本文定义视觉与品牌的「为什么」和基础 token；组件级规则（TurnCard、deixis、布局）见 [multivac-frontend-design.md](./multivac-frontend-design.md)。
> 原则：视觉基调不是品味问题，是定位的延伸——每个选择都应能从 ADR-001 推导出来。

---

## 0. 一句话基调

> **安静的书房 × 终端的血统——一台仪器，不是一个应用。**
>
> 打开它像走进一间深夜亮着一盏灯的工作室：纸是暖的，墨是静的，唯一发亮的是你指着的那个地方。

---

## 1. 基调的推导（四条，全部来自定位）

1. **介质要安静。** 这是个人每天待 6 小时、读多写少的地方。界面越有存在感，介质越失败——基调必须退后，让内容（代码、文档、视频、agent 的产出）成为唯一主角。
2. **颜色是信息，不是装饰。** 设计中颜色已有工作：agent attribution、TurnCard 状态、diff 红绿、gate 验收。要让语义色可读，**底色必须接近单色**——品牌色的滥用是在和信息抢带宽。
3. **厚度论的视觉化：时间感。** 产品的灵魂是沉淀，视觉要有「用得越久越好看」的材质感——纸、墨、档案馆；不是渐变玻璃和霓虹。
4. **差异化地图。** Cursor/Linear/Raycast 占「深色霓虹开发工具」，Notion 占「白色极简 SaaS」，Claude 占「奶油色人文主义」。留给我们且与定位吻合的空位：**暖纸 + 墨色 + 终端血统**——比 Claude 更工具，比 Cursor 更温暖，有 Multivac 这个名字应有的阿西莫夫式旧未来感。

---

## 2. 色彩：墨、纸、琥珀

### 2.1 主题色：琥珀

选琥珀不是因为好看，是因为隐喻精确：**琥珀是把上下文封存千万年的沉淀物**——这就是产品本身（D4：知识是工作的投影）。且它在竞品色谱上是空位（Linear 紫、Cursor 蓝黑、Claude 陶土橙）：暖色家族，色相清晰可分。

### 2.2 Token

```css
:root {
  /* ===== 基底：暖中性（不用 slate 蓝灰）===== */
  --background: #faf8f4;        /* 纸 */
  --foreground: #1c1a17;        /* 墨 */
  --surface: #f3f0ea;
  --surface-secondary: #ece8df;
  --border: #e4dfd5;
  --border-secondary: #eeeae1;

  /* ===== 品牌色：琥珀（克制使用，见 2.3）===== */
  --color-primary: #d97917;
  --color-primary-rgb: 217, 121, 23;

  /* ===== 语义色：独立的状态系统，降饱和 ===== */
  --color-success: #4d9960;     /* diff 新增 / gate 通过 */
  --color-error: #c4554d;       /* diff 删除 / 失败 */
  --color-warning: #d9a317;     /* 待批 / partial */
  --color-info: #5b7e9e;        /* 中性提示 */

  &[data-theme="dark"] {
    /* 石墨夜：暖黑微偏褐，不是纯黑 */
    --background: #161411;
    --foreground: #e8e4dc;
    --surface: #1f1c18;
    --surface-secondary: #282420;
    --border: #353029;
    --border-secondary: #2a2622;
  }
}
```

派生规则沿用 Epitaxy 模式：不用固定色阶，一律 `var(--foreground)` 或 `color-mix(in srgb, var(--color-primary) 10%, transparent)` 派生。语义色变，整个 UI 自动跟随。

**Agent 标识色**：在墨纸底上的一组降饱和分类色环（沿用前端文档 §5.2 的 `--color-agent-*`），与琥珀和语义色不冲突——agent 色只出现在 attribution 细标记上，不大面积铺。

### 2.3 琥珀纪律（比色值更重要）

**琥珀的出场率 < 5%。** 只允许出现在：

1. **Deixis 高亮**——选区、引用 chip、agent 回指的反向定位
2. **当前聚焦**——聚焦的 surface 边、活跃输入态
3. **品牌时刻**——logo、启动、空状态

界面 95% 的面积是墨与纸。效果：「用户指着的地方」永远是画面里最亮的事件——**视觉权重与交互权重一致，这就是介质论的视觉表达**。任何人想把按钮、图表、装饰刷成琥珀色，对照本条拒绝。

## 3. 字体：三种声音

| 声音 | 字体方向 | 用途 |
|------|---------|------|
| **工具**（UI） | 人文主义无衬线（Inter / Söhne 气质），小字号高密度 | 导航、标签、按钮、元信息 |
| **Agent 的话**（正文） | **衬线体**，可变字重 | ResponseCard 的回复正文——衬线让 agent 的「话」有人的声音、可长读，与 UI 的工具感分离（向 Claude 学的最值得学的一手） |
| **机器**（代码/终端） | 优质等宽（JetBrains Mono / Berkeley Mono 气质） | 代码、diff、终端面。终端是一等 surface，等宽字体是门面，值得花钱买一个好的 |

## 4. Logo：块状光标 ▮

### 4.1 提案

```
MULTIVAC▮
```

**字标**：等宽字体全大写，结尾一个琥珀色块状终端光标。**图标**单独使用时就是那个 `▮`（可带极细的层积线纹理）。

### 4.2 理由

1. 块状光标是**人和 agent 共同书写的那个点**——整个产品就是「共享同一个光标」的隐喻，deixis（指）的原语也在其中
2. 终端血统：Multivac 来自阿西莫夫,块状光标是对那个时代计算机最优雅的致敬，不需要画 CRT
3. 工程完美：单字符缩放到 favicon / menubar / 16px 不损失；暗亮主题只换颜色；闪烁动画即品牌动效
4. 备选方向曾考虑**年轮/地层**（呼应厚度论的沉淀隐喻），判定弱于光标：光标是动作，年轮是状态——产品的第一印象应该是动作

### 4.3 禁用清单

不用机器人、不用 ✨ 火花（AI 产品最大的视觉俗套）、不用对话气泡、不用大脑/电路板/六边形网格。

## 5. 材质与动效

- **轻边界**：1px 边框 + `--shadow-minimal`，没有大圆角大阴影的卡片堆（Craft Agents 验证过的工作台质感；z-index/shadow token 纪律见前端文档）
- **动效预算全部花在一处**：deixis island 的物理动画（从选区生长出来）。其余一切转场 ≤150ms 或没有
- **全产品禁 spinner 转圈**。agent 工作中的指示是呼吸感的微弱脉动 + 骨架态
- **Agent 现身的克制**：agent 在 surface 上的 attribution 是细色条/小标记，不是大头像满屏飞
- 暗色主题是「深夜工作室」（石墨暖黑），亮色主题是「纸面书房」——两个主题，不做主题引擎（前端文档已定）

---

## 6. 不做的事

| 不做 | 原因 |
|------|------|
| 品牌色大面积铺装 | 违反琥珀纪律（§2.3）——颜色是信息预算 |
| 渐变玻璃 / 霓虹 / glassmorphism | 与「沉淀、档案、仪器」的时间感冲突 |
| slate/蓝灰中性色 | 冷色基底与暖纸定位冲突（替换前端文档原占位 token） |
| spinner / 加载转圈 | 安静原则;用脉动与骨架态 |
| 机器人/火花/气泡/大脑类视觉符号 | AI 俗套，且与「工作台」身份不符 |
| 多主题引擎 | 一暗一亮做穿 |
