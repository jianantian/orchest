# 004 · Python 与 Node 的语音合成接口

## 背景

两端已对称提供 ASR 调用。Rust 已有 `Tts` 与统一事件流，双工能力在 003 接通，SDK 需要提供一次性、流式和双工访问。

## 目标与范围

让 Python 与 Node 从 provider wall 调用同一套 TTS 能力，透传类型化音频、生命周期、计量及错误。

## 验收标准

- [ ] 同一 fixture 在两端都能得到一次性合成结果和整段文本的流式音频，音频在 Python 为字节、Node 为字节数组，带格式信息。
- [ ] 双工用例并行追加文本和读取音频，并验证关闭。按 003 能力矩阵验证 Flush、取消旧上下文以及不支持操作的错误。两端暴露相同的上下文标识、已确认的 Flush 标识、计量与错误类别。
- [ ] 缺失或不支持的选项由 provider wall 拒绝，绑定转换结果与核心错误一致。关闭或回调异常后的资源释放有测试覆盖。
- [ ] 现有 ASR 与 SDK 0.2 的使用路径通过回归。三平台打包安装通过，指南列出支持矩阵、用量来源和版本对应关系。
