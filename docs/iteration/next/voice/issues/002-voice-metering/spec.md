# 002 · 语音计量与成本估算

## 背景

流结束事件目前携带 `TokenUsage`。Provider-core 已有毫秒计价和 `Cost`，没有面向语音的统一用量与字符计价。Rust 职责是给出可核对的用量和估算依据。

## 目标与范围

为语音增加类型化用量通路与字符计价，明确上游报告、对已知输入的估算及未知值的编码。

## 验收标准

- [ ] 在终止或结算路径中，调用者可读到具体 provider/model、音频时长或字符数、来源及可用的币种和成本估算。相同流的结算数据只发布一次。
- [ ] 有上游用量时按其语义透传。可按输入格式可靠计算时，已知长度 fixture 得到可复算估算。缺失计量、定价或格式信息时，相应字段保留未知。
- [ ] Unicode 与分段文本由 fixture 验证计数单位。记录 provider 自报的计费单位；本地估算使用公开的计数规则，标明估算来源。
- [ ] 取消、失败及正常结束可以区分。重试和空增量 fixture 不会凭空增加用量。已有 LLM token 结算和 ASR 事件使用方式通过回归测试。

## 依赖

001 的模型身份和定价字段。
