# 003 · 三个 TTS 方言的双工契约

## 背景

三个 TTS adapter 的整段输入路径能返回流式音频，`start_duplex_stream` 仍返回 `UnsupportedOperation`。ADR-0006 D7.5 允许将 Finalize 映射为 Flush，并以 Turn 表达合成上下文结束。

## 目标与范围

定义追加文本、Flush、取消上下文和关闭，分别接通 Aliyun、Volcengine、MiniMax。按实际协议能力确认边界。

## 验收标准

- [ ] 每个方言的可控 transport fixture 都在最终关闭前产生音频，后续文本仍可追加。每块音频有可验证的上下文及 Flush 归属，缺少对齐信息时对应字段可省略。
- [ ] Flush 的接受与完成可区分，完成事件只在当前边界可证明时发出，下一段输入仍可继续。若通过结束并续接 provider task 映射，fixture 明确证明上下文归属和顺序。
- [ ] 取消确认后旧上下文后续到达的音频不再交付。关闭与重复关闭可完成且释放 transport；握手失败、断连或不支持的操作返回明确错误。
- [ ] 保留每个方言的协议依据、录制或模拟契约测试，并记录真实服务 smoke 的覆盖结果。目录声明与已证实行为一致。

## 依赖

协议验证依赖 v1.2，目录及计量接线依赖 001、002。
