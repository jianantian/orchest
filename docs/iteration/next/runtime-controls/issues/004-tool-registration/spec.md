# 004 · Node 工具注册对齐与 SDK 验收

## 背景

Node 已有 schema、handler 和轮询式工具注册。Python 还提供 Agent-as-Tool 和内建写文件工具，Node 缺少对应入口。

## 目标与范围

补两项有现有语义的注册方法。用一组宿主示例串起工具、请求、异步运行和恢复。

## 验收标准

- [ ] Node 能将已配置的 Agent 注册为工具，输入键与 Python 对应行为一致。模型 fixture 调用后得到子 Agent 的结构化结果。
- [ ] Node 能注册内建写文件工具，以临时工作区验证允许和拒绝两条路径。schema、effects 与审批来自相同 Rust 工具定义。
- [ ] 原有 schema、handler 和轮询注册方法通过回归测试。两端公开示例成功运行，并覆盖按请求 ID 审批和会话恢复。
- [ ] 三平台 SDK 工作流通过。迁移指南标出公开 API 变化，候选版说明列出实际 Rust 基线。

## 依赖

注册本身独立，集成验收依赖 002、003。
