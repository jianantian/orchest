# 005 · Agent team pattern examples

## Background

Research suggested direct agent communication and team templates. These should first be validated as product-layer patterns.

## Goal

Provide examples/templates for agent team coordination using existing primitives.

## Acceptance Criteria

- [ ] Examples cover at least two team patterns using Agent-as-Tool, Handoff or watchers.
- [ ] Docs identify when existing primitives are sufficient.
- [ ] If direct peer-to-peer communication is required, a follow-up runtime issue is created with evidence.
- [ ] Examples compile and run in CI.
