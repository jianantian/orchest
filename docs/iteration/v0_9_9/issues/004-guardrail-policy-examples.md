# 004 · Guardrail policy examples

## Background

Research suggested a full policy engine, but Orchest's core design prefers extension through `Guardrail`.

## Goal

Provide examples for complex permission policies as application-layer guardrails.

## Acceptance Criteria

- [ ] Example covers multi-level authority or risk classification using existing guardrails.
- [ ] Docs explain why this remains app-layer.
- [ ] Example compiles and runs in CI.
- [ ] Any proven core gap is documented separately.
